## 0. 확정된 설계 결정 (변경 가능, 추후 재검토 시 참고)

- **연습모드는 "몰입형" UI로 확정**: 앱 카드 안에 작은 기계 그림을 넣는 방식이 아니라, 연습모드 진입 시 화면 전체가 해당 매장의 키오스크 화면 그 자체처럼 보이도록 한다(배경/버튼 스타일까지 매장별 스킨 적용). 앱의 도움 요소(음성 안내, 진행률)는 화면 위에 떠 있는 최소한의 오버레이로만 존재한다.
- **실시간 안내 모드는 기존 앱 스타일 유지**: 실물 기계가 눈앞에 있으므로, 화면을 기계처럼 재현할 필요 없이 일반 앱 UI로 옆에서 돕는다.
- ⚠️ 이 결정은 프로토타입 단계에서 나온 방향이며, 실제 사용자 테스트 결과에 따라 바뀔 수 있음. 변경 시 이 섹션을 갱신할 것.

## 1. 전체 내비게이션 구조

```
하단 탭바 (3개)
├── 홈 (매장 검색, 최근 이용, 진입점)
├── 내 주문 (저장된 주문 목록)
└── 설정 (접근성: 글씨크기, 음성, 고대비, 언어)

주문 흐름 (홈에서 스택으로 진입, 탭바 숨김)
홈 → 매장 선택 → 모드 선택 → [연습모드 | 실시간모드] → 완료 → 홈으로 복귀
```

- **탭바는 주문 흐름 진행 중(매장 선택 이후)에는 숨김** — 흐름 이탈로 인한 혼란 방지, 대신 상단에 "뒤로가기"만 노출
- 최초 실행 시 온보딩(1회) → 이후 항상 홈에서 시작

## 2. 화면 목록

| ID | 화면명 | 진입 경로 | 목적 | 이탈 조건 |
|---|---|---|---|---|
| S00 | 스플래시 | 앱 실행 | 로딩, 1초 이내 자동 전환 | 자동 |
| S01 | 온보딩 (최초 1회) | 최초 설치 후 | 글씨 크기/음성 기본값 설정, 앱 목적 3장 이내 소개 | "시작하기" 버튼 |
| S02 | 홈 | 탭바 / 앱 시작 | 매장 검색, 최근 이용 매장, 저장된 내 주문 바로가기 | 매장 카드 탭 |
| S03 | 매장 검색/선택 | 홈 > 검색 | 브랜드/매장명 검색, GPS 기반 근처 매장 추천(서브웨이만 노출, MVP) | 매장 선택 |
| S04 | 모드 선택 | 매장 선택 후 | "연습하기" vs "지금 매장이에요" 두 개 큰 버튼 | 버튼 탭 |
| S05 | 가상 키오스크 - 단계 화면 (반복) | 모드선택 > 연습 | 실제 키오스크와 동일한 순서로 선택지 노출 (빵→굽기→치즈→야채→소스→사이드) | 다음 단계로 이동 |
| S06 | 모의 결제 연습 | S05 마지막 단계 | 실제 키오스크 결제 화면 재현 (카드/페이/영수증), 실결제 미처리 | "연습 완료" |
| S07 | 연습 완료 & 저장 | S06 이후 | 오늘 연습한 조합 요약, "내 주문으로 저장" 여부 선택 | 홈으로 |
| S08 | 실시간 안내 - 시작 확인 | 모드선택 > 실시간 | 저장된 내 주문 불러오기 or 처음부터 선택 | 시작 버튼 |
| S09 | 실시간 안내 - 단계 화면 (반복) | S08 이후 | 큰 글씨+음성으로 "지금 키오스크에서 할 일" 안내, "다시 설명해줘"/"직원 호출" 버튼 상시 노출 | 다음 단계로 이동(사용자 수동 확인) |
| S10 | 실시간 안내 - 결제 안내 | S09 마지막 단계 | 결제 화면 안내 (실제 결제는 키오스크에서 진행함을 명시) | "완료" |
| S11 | 완료 & 만족도 평가 | S10 이후 | 이모지 1탭 평가, 오늘 주문 저장 여부 | 홈으로 |
| S12 | 내 주문 관리 | 탭바 | 저장된 주문 목록, 수정/삭제, 이름 지정(예: "내가 좋아하는 조합") | - |
| S13 | 설정 | 탭바 | 글씨 크기, 음성 on/off, 고대비 모드, 언어(추후) | - |
| S14 | 직원 호출 확인(모달) | S09에서 트리거 | "직원을 호출할까요?" 확인, 취소 시 안내 계속 | 확인/취소 |

## 3. 화면별 접근성 요구사항 (모든 주문 흐름 화면 공통 적용)

- 텍스트 최소 크기 18pt 이상 (설정에서 최대 200%까지 확대 가능)
- 모든 주요 버튼에 음성 안내 자동 재생 옵션 (설정에서 on/off)
- 버튼 터치 영역 최소 48x48pt
- 색상만으로 정보 구분 금지 (아이콘/텍스트 병행)
- "다시 설명해줘" 버튼은 화면 하단 고정 위치로 항상 동일한 자리에 노출 (학습 효과)

---

## 4. 상태(State) 설계 메모

- **S05/S09 (단계 화면)**: `current_step_index`, `store_flow_id`, `selected_options[]` 를 흐름 전체에서 유지해야 함 → 설계 단계에서 로컬 상태 관리 방식(Context/Provider 등) 결정 필요
- **S06/S10 (결제)**: 결제 관련 상태는 서버로 전송하지 않음 (개인정보/보안), 클라이언트 로컬 상태로만 처리 후 화면 종료 시 폐기
- **S07/S11 (완료)**: "저장" 선택 시에만 `saved_orders` 로컬(또는 서버) 저장소에 기록
